## ✨ المميزات
* **دقة المواعيد:** يعتمد على بيانات محلية لكل محافظة.
* **لمسة رمضانية:** حساب تلقائي لوقت الإمساك (قبل الفجر بـ 15 دقيقة).
* **تجربة مستخدم سلسة:** واجهة ليلية مريحة للعين مع دعم كامل للهواتف.
* **تطبيق ويب تقدمي (PWA):** يمكن تثبيته على الشاشة الرئيسية ويعمل بدون إنترنت.
* **التنقل الذكي:** إمكانية الانتقال بين الأيام واختيار تاريخ محدد.

---

## 🚀 التقنيات المستخدمة
* **HTML5 & CSS3:** تصميم عصري بواجهة زجاجية (Glassmorphism).
* **JavaScript (Vanilla):** إدارة منطق العد التنازلي والمواقيت بكفاءة عالية.
* **CSV Data:** تخزين البيانات بشكل خفيف وسريع الاستجابة.
